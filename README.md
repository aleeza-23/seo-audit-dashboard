# SEO Audit Dashboard

An AI-assisted frontend application that analyses websites and provides an SEO score, identifies common SEO issues, and gives actionable recommendations.

## Planned Tech Stack

- React
- Vite
- JavaScript
- CSS
- Git and GitHub

## Getting Started

Prerequisites: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal (typically `http://localhost:5173`).
